# Edge RAM Saver

Лёгкое расширение для Microsoft Edge (Manifest V3), которое выгружает неактивные вкладки из
оперативной памяти через `chrome.tabs.discard()`. Вкладка остаётся в панели — фавиконка и заголовок
на месте, — но её процесс убивается. При клике страница перезагружается сама.

Без сборки, без зависимостей, без постоянных content-скриптов. Итоговый размер — около 30 КБ.

## Возможности

- **Авто-выгрузка** неактивных вкладок через заданное время (по умолчанию 15 минут).
- **Защита медиа**: вкладка со звуком не трогается никогда; дополнительно перед выгрузкой
  выполняется разовая проверка страницы, которая ловит и **беззвучное/замьюченное видео**,
  Picture-in-Picture и полноэкранный режим.
- **Защита форм**: вкладка с незакоммиченным вводом (набранный, но не отправленный текст) не выгружается.
- **Белый список** доменов — с поддержкой поддоменов (`example.com` покрывает `mail.example.com`).
- **Паник-кнопка** «Усыпить все неактивные сейчас».
- **Бейдж** на иконке показывает, сколько вкладок сейчас спит.
- Интерфейс на русском и английском (берётся из языка браузера).

## Установка в Microsoft Edge

1. Положите папку `edgeaddon` в постоянное место на диске. Edge подгружает распакованное
   расширение с диска при каждом запуске — если папку переместить или удалить, расширение отвалится.
2. Откройте `edge://extensions/`.
3. Включите тумблер **«Режим разработчика»** — он в левой нижней части страницы.
4. Нажмите **«Загрузить распакованное»** и выберите папку `edgeaddon` (ту, где лежит `manifest.json`).
5. Закрепите иконку на панели: `⋯` справа от адресной строки → **«Расширения»** → значок глаза
   напротив Edge RAM Saver.
6. Откройте popup и настройте таймер под себя.

### Рекомендация

У Edge есть собственная функция «Спящие вкладки» (`edge://settings/system`). Две системы будут
бороться за одни и те же вкладки — лучше оставить что-то одно. Встроенная не умеет в белый список
и проверку форм, поэтому её обычно отключают.

## Проверка, что всё работает

- `edge://discards` — таблица всех вкладок, колонка **Discarded** показывает выгруженные.
- `Shift + Esc` — диспетчер задач браузера: процессы выгруженных вкладок исчезают из списка.
- `edge://extensions/` → ссылка **«служебный работник»** под расширением открывает консоль
  service worker'а для отладки.

Быстрый тест: выставьте таймер в 1 минуту, откройте несколько вкладок, переключитесь на другую и
подождите. Через минуту неактивные вкладки станут спящими.

## Структура

```
manifest.json      # MV3: permissions tabs / storage / alarms / scripting
background.js      # service worker: учёт активности, alarms, выгрузка
popup.html/css/js  # интерфейс: таймер, тумблеры, белый список, паник-кнопка
_locales/          # ru + en
icons/             # 16 / 32 / 48 / 128 px
tools/make-icons.ps1  # перегенерация иконок (нужна только если хотите свой дизайн)
```

## Как это устроено

Service worker в MV3 умирает через ~30 секунд простоя, поэтому расширение не хранит состояние в
памяти:

- время последней активности каждой вкладки лежит в `chrome.storage.session` (только RAM, на диск
  не пишется), отдельным ключом на вкладку;
- ключи закрытых вкладок удаляются по `tabs.onRemoved`, плюс на каждом проходе подчищаются
  «осиротевшие» — набор не растёт;
- вместо `setInterval` используется **один адаптивный будильник**: расширение считает ближайший
  момент, когда какая-то вкладка сможет быть выгружена, и просыпается ровно к нему. Если выгружать
  нечего — будильник не создаётся вовсе.

Проверка «страница занята?» — это одна инъекция `chrome.scripting.executeScript` во все фреймы
непосредственно перед выгрузкой. Постоянных content-скриптов нет, на страницах не остаётся
ни байта кода. Если инъекция не удалась (служебная страница, PDF-viewer), вкладка **не** выгружается —
лучше не сэкономить память, чем потерять недописанный текст.

## Ограничения

- `<all_urls>` в host_permissions нужен только для этой разовой проверки. Если такие права
  нежелательны — выключите в popup тумблеры «Вкладки с видео» и «Вкладки с несохранённым вводом»:
  тогда инъекции не выполняются вовсе, а защита медиа останется на уровне флага «вкладка звучит».
- Некоторые сайты подставляют значения в поля скриптом. Такое поле может выглядеть как
  «несохранённый ввод», и вкладка не будет усыпляться. Лечится выключением тумблера форм.
- Минимальный интервал будильника в MV3 — 1 минута, поэтому таймер меньше минуты не имеет смысла.
